# Agent rules

## Punctuation (unbreakable)

Never use an em dash (Unicode U+2014). Never use two consecutive ASCII hyphens as punctuation. Both marks are banned in commits, comments, docs, PR text, chat replies, and user-facing copy.

Do not swap an em dash for two hyphens. Use a comma, colon, period, or parentheses.

This ban is absolute. Do not use either mark for asides, appositions, or interrupted clauses.

Required command-line flags that start with two hyphens are a tool constraint, not punctuation. Do not write two hyphens in prose.
