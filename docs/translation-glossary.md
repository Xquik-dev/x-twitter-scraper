## Meaning rules

- Distinguish an Xquik API key from an official X developer account.
- Distinguish supported scraping from private reads and X account actions.
- Never imply that scraping needs a connected X account.
- Never imply that every deduplicated row has a proven billing outcome.
- Label dated prices, counts, versions, and competitor claims.
- Keep legal wording exactly as supplied in every README.
- Keep testimonial text exact. Do not fix grammar or punctuation.
- Keep the original beside any translated testimonial.
