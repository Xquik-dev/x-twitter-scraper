## Review rules

- Record the source URL and review date.
- Label every vendor comparison as a claim.
- Verify prices against the named provider's current pricing page.
- Verify contracts against product docs or machine-readable schemas.
- Do not reuse testimonials, branding, or vendor copy.
- Remove stale measurements instead of carrying them forward.
