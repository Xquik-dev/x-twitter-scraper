# Apify Twitter Scrapers source review

- Reviewed: 2026-08-22
- Source: [Apify Twitter Scrapers](https://apify.com/scrapers/twitter)
- Source type: Marketplace category page

## Audience

No-code users and developers who want hosted scraping jobs and exports.

## Questions answered

- Which X objects can marketplace Actors collect?
- Can runs be scheduled and monitored?
- Which export and integration options exist?
- How does a user start without writing a scraper?

## Claims recorded

Apify presents profiles, posts, search, hashtags, mentions, and engagement. It
also emphasizes scheduling, logs, retries, proxies, datasets, exports, and MCP.

## Evidence and examples

The category page shows input steps and example records. It links individual
Actors and their API tabs. Each Actor owns its input, schema, cost, and support.

## Pricing record

The page contains prices from individual Actor cards. Apify platform usage can
also apply. A cost study must record both the Actor charge and platform plan.

The Xquik Actor price box was checked separately on 2026-08-22. Paid Apify
plans showed $0.00015 per delivered row. The free plan showed $0.015 per row.
The README labels both prices and tells users to check before each run.

## Structure and requested action

The page uses example data, a short setup sequence, use cases, and Actor cards.
Calls to action open the store, console, or an Actor API page.

from direct API billing. Link the exact Actor contract.
