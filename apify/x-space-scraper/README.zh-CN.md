Xquik 是全球最快、最便宜的 X（Twitter）抓取服务，X 数据也最完整。Xquik 的 X Space Scraper 按关键词、主持人或话题标签查找空间&按 URL 或 ID 读取空间&直播。其他大多数 Apify Actor 在过滤或去重之前就开始收费。Xquik 只对已交付且不重复的结果收费。

查找任意话题的 Twitter 空间，无论是正在直播、已预定还是已结束。你不需要 X API 密钥或登录。费用为**每个已交付空间或直播 $0.00015** & Apify 另行收取平台使用费。

> “Twitter”和“X”是 X Corp 的商标。

## 空间数据

- 每个空间的标题、状态&预定时间、开始时间&结束时间。
- 实时听众数、回放播放次数&当前在空间中的账号。
- 主持人的公开个人资料、联合主持人、发言人 & X 列出的听众。
- 回放、剪辑&锁定设置，以及宣布该空间的帖子，包含正文、各项计数&作者。
- 主持人&发言人在空间中分享的帖子，附带每条帖子的分享者&分享时间。
- 已结束空间的录音。开启 `includeReplay` 后，以 HLS 播放列表 URL 的形式提供。
- 按 URL 或 ID 读取的直播，包含标题、状态、时间、观看数&主持人。
- 计费前去除重复项。2 个搜索词找到的同一个空间只算 1 行。

## 如何查找 X 空间

刚接触 Apify？先[创建免费账号](https://console.apify.com/sign-up?fpr=xquik)。免费套餐不需要信用卡&每月提供 $5 可用额度。按每个空间或直播 $0.00015 计算，不算平台用量，$5 最多可支付 33,000 个空间或直播。然后回到这里&点击 Try for free。

1. 在 Apify Console 中打开 Xquik 的 X Space Scraper。
2. 在 `searchTerms` 中输入词语、话题标签或 X 搜索运算符。
3. 或者把空间 URL 粘贴到 `startUrls`，或把空间 ID 粘贴到 `spaceIds`。
4. 读取直播时，把直播 URL 粘贴到 `startUrls`，或把直播 ID 粘贴到 `broadcastIds`。
5. 设置 `maxItems` 限制交付的行数，然后点击 Start。
6. 以 JSON、CSV 或 Excel 格式下载数据集，或使用 Apify API。

`startUrls` 中的每个 URL 可以写成普通字符串，也可以写成 `{ "url": "..." }` 对象。

```json
{
  "startUrls": [
    "https://x.com/i/spaces/1OGwblLjnQMKB",
    { "url": "https://x.com/i/broadcasts/1nGeLMWbkpaKX" }
  ]
}
```

## 输入

```json
{
  "searchTerms": ["bitcoin", "from:solana"],
  "queryType": "Latest",
  "maxItems": 1000
}
```

搜索词会找到匹配帖子所分享的空间。它支持 X 搜索所支持的运算符。

| 目标                 | 搜索词             |
| -------------------- | ------------------ |
| 某个话题的空间       | `bitcoin`          |
| 某个账号分享的空间   | `from:solana`      |
| 某个话题标签下的空间 | `#AI`              |
| 1 种语言的空间       | `startups lang:es` |
| 高赞帖子分享的空间   | `nba min_faves:50` |

`queryType` 决定哪些帖子排在前面。`Latest` 把最新的帖子排在前面 & `Top` 把互动最多的帖子排在前面。

`Live` 列出正在直播的空间&`Upcoming` 列出已预定的空间。两者都读取 X 自己的空间搜索，它匹配空间标题中的词&不支持运算符。

```json
{ "searchTerms": ["bitcoin"], "queryType": "Live" }
```

按 URL 或 ID 读取你已经知道的空间。

```json
{
  "startUrls": [{ "url": "https://x.com/i/spaces/1OGwblLjnQMKB" }],
  "spaceIds": ["1OGwblLjnQMKB"]
}
```

开启 `includeReplay`，即可获取每个已结束空间的录音。

```json
{ "spaceIds": ["1OGwblLjnQMKB"], "includeReplay": true }
```

这时该行会带上 `replay`，其中有作为 HLS 播放列表的 `url`，以及 `streamType` & `status`。正在直播、已预定或没有录音的空间不带 `replay`。录音不额外收费。

按 URL 或 ID 读取直播，也就是 X 在 `x.com/i/broadcasts` 上托管的实时视频。

```json
{
  "startUrls": [{ "url": "https://x.com/i/broadcasts/1nGeLMWbkpaKX" }],
  "broadcastIds": ["1nGeLMWbkpaKX"]
}
```

顺利完成的小型运行会跳过 `run-report` & 节省 Apify 用量。开启 `alwaysSaveRunRecords` 后，每次运行都会写入报告。

## 输出

每行包含 1 个空间或直播&在 `sourceTarget` 中记录它的搜索词、URL 或 ID。`resultType` 为 `space` 或 `broadcast`。

示例使用样例值。实际结果反映实时数据。空间行如下所示。

```json
{
  "id": "1SampleSpace1",
  "title": "Sample Space about bitcoin",
  "state": "Ended",
  "startedAt": "2026-03-11T17:00:26.227Z",
  "endedAt": "2026-03-11T17:49:29.190Z",
  "totalLiveListeners": 841,
  "totalReplayWatched": 609,
  "isAvailableForReplay": true,
  "creator": { "username": "sample_host", "name": "Sample Host" },
  "admins": [{ "username": "sample_host", "name": "Sample Host" }],
  "speakers": [{ "username": "sample_speaker", "name": "Sample Speaker" }],
  "listeners": [],
  "sharings": [
    {
      "id": "2106511178339881415",
      "sharedAt": "2026-03-11T17:20:16.658Z",
      "sharedBy": { "username": "sample_speaker", "name": "Sample Speaker" },
      "tweet": { "id": "2105620368836706789", "text": "Sample shared post" }
    }
  ],
  "resultType": "space",
  "sourceTarget": "bitcoin"
}
```

`state` 为 5 个值中的 1 个，沿用 X 的命名。

| `state`      | 该空间                            |
| ------------ | --------------------------------- |
| `NotStarted` | 已预定&带有 `scheduledStart`。    |
| `Running`    | 正在直播。                        |
| `Ended`      | 已结束。由主持人结束。            |
| `TimedOut`   | 已结束。由 X 关闭，而不是主持人。 |
| `Canceled`   | 曾经预定，但从未开始。            |

`Ended` & `TimedOut` 的空间带有 `endedAt`，&两者都可能保留录音。面向订阅者或社群的空间，X 只向对应受众展示，所以这些空间不返回任何行。

直播行带有 `resultType: "broadcast"`，如下所示。

```json
{
  "id": "1SampleBcast1",
  "title": "Sample launch broadcast",
  "state": "Ended",
  "startedAt": "2026-09-17T00:54:56.506Z",
  "endedAt": "2026-09-17T01:17:35.036Z",
  "totalWatched": 161758,
  "totalWatching": 21639,
  "width": 3840,
  "height": 2160,
  "creator": { "username": "sample_host", "name": "Sample Host" },
  "resultType": "broadcast",
  "sourceTarget": "1SampleBcast1"
}
```

## 输出列

运行读到每行后，8 个输入会调整该行的形式。它们不运行代码&不改变价格。

| 字段                | 作用                                        |
| ------------------- | ------------------------------------------- |
| `fields`            | 只保留这些字段，顺序&拼写与你写的一致       |
| `omitFields`        | 去掉这些字段&保留其余字段                   |
| `renameFields`      | 把字段移到使用新名称的列中                  |
| `flatten`           | 把每个嵌套对象展开为顶层列                  |
| `fillMissingFields` | 某行缺少保留的字段时，填入 `null`。默认开启 |
| `joinFields`        | 把这些列表各自合并为 1 个文本值             |
| `joinSeparator`     | 合并项之间的文本。默认是逗号&空格           |
| `constantFields`    | 添加每行文本都相同的列                      |

- 用点号表示对象内的字段。大小写&下划线都没有影响。
- 每行都保留它的 `id`。
- 使用 `fields` 时，某行缺少的字段会以 `null` 输出。这样每行的列都相同。
- 字段名写错时，运行会在读取前停止&不收取任何费用。
- 如果无法检查字段名，运行会继续读取&把未见过的字段名列在最后。
- 运行会忽略为其他 Actor 编写的映射函数或 jq 过滤器。

## 限制&恢复

提取中断时，会写入免费的 `partial` 诊断。已获取的结果不受影响。重试前，先查看 `availableResults`、`failedTargets`、`retryable` & `nextAction`。Actor 成功退出只说明结果已交付，不代表提取完整。

运行状态会写明提前停止的每个原因。`stopCauses` 列出每个原因，并附上各自的 `message`、`retryable` & `nextAction`。原因包括 `target_not_found`、`target_failed`、`pagination_safety_limit` & `deadline_reached`。只有在其他原因让运行停止时，缺失的目标才会列入其中。只要任何原因可重试，整个运行就是 `retryable`。

## 常见问题

先解答常见问题，再说明在哪里获取帮助。

### 我需要 X API 密钥或登录吗？

不需要。Xquik 的 X Space Scraper 不需要 X API 密钥、登录或任何凭据。

### 能找到正在直播的空间吗？

能。把 `queryType` 设为 `Live`&添加一个搜索词，例如 `bitcoin`。每行都是一个正在直播的空间。`Upcoming` 列出已预定的空间，这些行带有 `scheduledStart`。

### 抓取 X 空间合法吗？

Xquik 的 X Space Scraper 请求的是公开的 X 字段。结果可能包含个人数据。请确认用途合法&遵守适用的隐私规定。不确定时，请咨询专业律师。

### 为什么我的运行没有返回结果？

先查看运行状态。空运行的状态会提示你检查目标。出现需要注意的情况时，会生成免费的 `diagnostics` 输出。其中的 `stopCauses` 为每个原因给出可以照做的 `nextAction`。

### 可以使用 API、定时调度&集成吗？

可以。使用 Apify API 或 Xquik REST API。[API 标签页](https://apify.com/xquik/x-space-scraper/api) 提供 Python、JavaScript & cURL 示例。Apify [定时调度](https://docs.apify.com/platform/schedules) 可以按 cron 运行 Xquik 的 X Space Scraper。Agent 使用 [Apify MCP](https://docs.apify.com/platform/integrations/mcp)。除非需要旧版构建，否则请使用 `latest`。

### 在哪里获取帮助？

在 [Issues 标签页](https://apify.com/xquik/x-space-scraper/issues) 提交 issue，并附上运行 ID。键值存储中的免费诊断信息会说明需要注意的运行。没有返回任何行的运行，会在状态中说明原因。

### 可以获得定制方案吗？

可以。在 [Issues 标签页](https://apify.com/xquik/x-space-scraper/issues) 中说明你的需求。Xquik 还提供仪表盘、REST API、MCP 服务器 & webhook。在 Xquik 的 [Apify 主页](https://apify.com/xquik) 上可以找到它的网站。
