Xquik es el servicio de scraping de X (Twitter) más rápido y económico del
mundo, con los datos de X más completos. X Media Downloader de Xquik extrae o
guarda fotos, videos & GIFs de posts & perfiles. La mayoría de los demás Actores
de Apify cobran antes de filtrar o quitar duplicados. Xquik solo cobra los
resultados entregados, únicos y que cumplen tus filtros.

Descarga contenido multimedia de Twitter o extrae URLs directas de posts & de la
pestaña Multimedia de los perfiles. Pagas **$0.00015 por fila entregada**, &
Apify factura aparte el uso de la plataforma. No necesitas clave de API de X ni
iniciar sesión.

> Xquik es un servicio independiente de terceros. No está afiliado a X Corp.
> "Twitter" y "X" son marcas registradas de X Corp.

## Archivos multimedia & metadatos

- Contenido multimedia de posts, perfiles, respuestas, citas & hilos en bloque.
- Fotos, GIFs, calidades de MP4 & listas de reproducción HLS.
- Subtítulos de posts con video, con tiempos & texto completo.
- Metadatos, URLs directas & los filtros disponibles.
- Almacenamiento de archivos dentro de los límites de la ejecución, con enlaces
  en la salida.
- Eliminación de duplicados antes del cobro.

## Cómo descargar contenido multimedia de X

¿Recién llegas a Apify? Primero
[crea una cuenta gratis](https://console.apify.com/sign-up?fpr=xquik). El plan
gratuito no pide tarjeta de crédito & te da $5 para gastar cada mes. A $0.00015
por fila de contenido multimedia, $5 alcanzan para hasta 33,000 filas de
contenido multimedia, sin contar el uso de la plataforma. Luego vuelve aquí &
haz clic en Try for free.

1. Abre X Media Downloader de Xquik en Apify Console.
2. Agrega nombres de usuario en `twitterHandles` o URLs de posts en `startUrls`.
3. Elige `sources` & activa `downloadMedia` para guardar los archivos.
4. Define `maxItems` para limitar las filas entregadas & luego haz clic en
   Start.
5. Descarga el dataset en JSON, CSV o Excel, o usa la API de Apify.

`startUrls` & `profileUrls` aceptan cada URL como texto simple o como objeto
`{ "url": "..." }`.

```json
{ "profileUrls": ["https://x.com/nasa", { "url": "https://x.com/OpenAI" }] }
```

`profileUrls` & `tweetIds` también sirven como objetivos.

## Entrada

```json
{
  "twitterHandles": ["OpenAI"],
  "sources": ["profiles"],
  "downloadMedia": true,
  "maxItems": 10000
}
```

Con un objetivo alcanza. Activa `downloadMedia` para guardar los archivos. Los
archivos de más de 80 MB quedan solo como URL.

Activa `includeSubtitles` para obtener los subtítulos de los posts de `tweetIds`
o `startUrls`. Cada post cuyo video tiene subtítulos agrega 1 fila con todas sus
pistas de subtítulos. Un post sin video o sin subtítulos no agrega ninguna fila
& no cuesta nada.

```json
{ "tweetIds": ["2104593672624886205"], "includeSubtitles": true }
```

Las ejecuciones pequeñas sin problemas omiten `run-report` & ahorran uso de
Apify. Activa `alwaysSaveRunRecords` para escribirlo en todas las ejecuciones.

## Salida

Las filas incluyen disponibilidad, metadatos & URLs de acción. Las filas
guardadas agregan `storedMediaUrl` & `downloadStatus: "stored"`. **Stored Media
Files** abre los registros guardados.

Los ejemplos usan valores de muestra. Los resultados reflejan datos en vivo. Una
fila de foto se ve así.

```json
{
  "type": "photo",
  "width": 1200,
  "height": 675,
  "altText": "Sample alt text",
  "sourceTarget": "OpenAI"
}
```

Una fila de subtítulos tiene `resultType: "subtitles"` & sus pistas de
subtítulos en `tracks`.

```json
{
  "resultType": "subtitles",
  "tweetId": "2104593672624886205",
  "tracks": [
    {
      "language": "en",
      "name": "Sample captions.srt",
      "autoGenerated": false,
      "url": "https://video.twimg.com/subtitles/sample.vtt",
      "text": "Sample caption text.",
      "cues": [{ "startMs": 0, "endMs": 3370, "text": "Sample caption text." }]
    }
  ]
}
```

`autoGenerated` es `true` cuando X transcribió el audio por su cuenta. `url`
enlaza el archivo WebVTT de la pista. Los filtros de contenido multimedia no
quitan las filas de subtítulos. Con `downloadMedia` activado, una fila de
subtítulos tiene `downloadStatus: "url-only"`.

## Columnas de salida

8 campos de entrada dan forma a cada fila después de que la ejecución la lee. No
ejecutan código & no cambian el precio.

| Campo               | Qué hace                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------ |
| `fields`            | Conserva solo estos campos, en el orden & la forma en que los escribes                     |
| `omitFields`        | Quita estos campos & conserva el resto                                                     |
| `renameFields`      | Mueve un campo a una columna con un nombre nuevo                                           |
| `flatten`           | Convierte cada objeto anidado en columnas de primer nivel                                  |
| `fillMissingFields` | Llena con `null` un campo conservado que falta en una fila. Activo de forma predeterminada |
| `joinFields`        | Convierte cada una de estas listas en 1 valor de texto                                     |
| `joinSeparator`     | Texto entre los elementos unidos. El valor predeterminado es una coma & un espacio         |
| `constantFields`    | Agrega una columna con el mismo texto en cada fila                                         |

- Usa un punto para un campo dentro de un objeto. Las mayúsculas & los guiones
  bajos no importan.
- Cada fila conserva su `id`.
- Con `fields`, un campo que falta en una fila llega como `null`. Así, todas las
  filas tienen las mismas columnas.
- Un nombre de campo incorrecto detiene la ejecución antes de leer & no cobra
  nada.
- Si no se pueden comprobar los nombres, la ejecución sigue leyendo & al final
  enumera los nombres que no encontró.
- La ejecución ignora una función de mapeo o un filtro jq escrito para otro
  Actor.

## Límites & recuperación

Una extracción interrumpida escribe un diagnóstico `partial` gratis. Los
resultados disponibles se conservan. Lee `availableResults`, `failedTargets`,
`retryable` & `nextAction` antes de reintentar. Una salida exitosa del Actor
confirma la entrega, no una extracción completa.

El estado de la ejecución nombra cada causa de una detención anticipada.
`stopCauses` enumera cada causa con su propio `message`, `retryable` &
`nextAction`. Las causas son `target_not_found`, `target_suspended`,
`target_failed`, `pagination_safety_limit`, `reply_reach` & `deadline_reached`.
`target_suspended` nombra las cuentas que X suspendió. `reply_reach` significa
que X entregó solo una parte de un hilo de respuestas. Un objetivo inexistente o
suspendido entra en la lista solo si otra causa detuvo la ejecución. La
ejecución es `retryable` si alguna causa lo es.

## Preguntas frecuentes

Respuestas a preguntas comunes y, luego, dónde conseguir ayuda.

### ¿Necesito una clave de API de X o iniciar sesión?

No. X Media Downloader de Xquik no necesita clave de API de X, inicio de sesión
ni credenciales.

### ¿Es legal descargar contenido multimedia de X?

X Media Downloader de Xquik solicita campos públicos de X. Los resultados pueden
contener datos personales. Confirma que tu propósito es lícito & cumple las
normas de privacidad aplicables. Si tienes dudas, consulta a un abogado
calificado.

### ¿Por qué mi ejecución no devolvió resultados?

Lee primero el estado de la ejecución. El estado de una ejecución vacía te pide
revisar tus objetivos & filtros. La salida gratuita `diagnostics` aparece cuando
algo requiere atención. Su `stopCauses` da a cada causa un `nextAction` que
puedes seguir. La ejecución enumera cada entrada que no puede leer & explica
cómo corregirla.

### ¿Puedo usar la API, las programaciones & las integraciones?

Sí. Elige entre 50 tareas públicas o la API REST de Xquik. La
[pestaña API](https://apify.com/xquik/x-media-downloader/api) tiene ejemplos en
Python, JavaScript & cURL. Las
[programaciones](https://docs.apify.com/platform/schedules) de Apify ejecutan X
Media Downloader de Xquik con un cron. Los agentes usan
[Apify MCP](https://docs.apify.com/platform/integrations/mcp). Usa `latest`
salvo que necesites una compilación anterior.

### ¿Dónde consigo ayuda?

Abre un issue en la
[pestaña Issues](https://apify.com/xquik/x-media-downloader/issues) con el ID de
la ejecución. Los diagnósticos gratuitos del almacén de clave-valor explican las
ejecuciones que requieren atención. Una ejecución que no recibe ninguna fila
explica el motivo en su estado.

### ¿Puedo obtener una solución a medida?

Sí. Describe lo que necesitas en la
[pestaña Issues](https://apify.com/xquik/x-media-downloader/issues). Xquik
también ofrece un panel, una API REST, un servidor MCP & webhooks. Encuentra el
sitio web de Xquik en su [perfil de Apify](https://apify.com/xquik).
