Xquik 是全球最快、最便宜的 X（Twitter）抓取服务，X 数据也最完整。Xquik 的 X Media Downloader 从帖子&个人资料中提取或存储照片、视频 & GIF。其他大多数 Apify Actor 在过滤或去重之前就开始收费。Xquik 只对已交付、不重复且符合过滤条件的结果收费。

从帖子&个人资料的“媒体”标签页下载 Twitter 媒体或提取直链 URL。费用为**每个已交付行 $0.00015** & Apify 另行收取平台使用费。你不需要 X API 密钥或登录。

> Xquik 是独立的第三方服务，与 X Corp 无关联。
> “Twitter”和“X”是 X Corp 的商标。

## 媒体文件&元数据

- 批量获取帖子、个人资料、回复、引用&帖子串中的媒体。
- 照片、GIF、多种 MP4 画质 & HLS 播放列表。
- 视频帖子的字幕，带时间信息&完整文本。
- 元数据、直链 URL & 可用的过滤条件。
- 在运行限制内存储文件，并在输出中给出链接。
- 计费前去除重复项。

## 如何下载 X 媒体

刚接触 Apify？先[创建免费账号](https://console.apify.com/sign-up?fpr=xquik)。免费套餐不需要信用卡&每月提供 $5 可用额度。按每条媒体行 $0.00015 计算，不算平台用量，$5 最多可支付 33,000 条媒体行。然后回到这里&点击 Try for free。

1. 在 Apify Console 中打开 Xquik 的 X Media Downloader。
2. 把用户名添加到 `twitterHandles`，或把帖子 URL 添加到 `startUrls`。
3. 选择 `sources` & 开启 `downloadMedia` 来存储文件。
4. 设置 `maxItems` 限制交付的行数，然后点击 Start。
5. 以 JSON、CSV 或 Excel 格式下载数据集，或使用 Apify API。

`startUrls` & `profileUrls` 中的每个 URL 可以写成普通字符串，也可以写成 `{ "url": "..." }` 对象。

```json
{ "profileUrls": ["https://x.com/nasa", { "url": "https://x.com/OpenAI" }] }
```

`profileUrls` & `tweetIds` 也可以作为目标。

## 输入

```json
{
  "twitterHandles": ["OpenAI"],
  "sources": ["profiles"],
  "downloadMedia": true,
  "maxItems": 10000
}
```

1 个目标就够了。开启 `downloadMedia` 来存储文件。超过 80 MB 的文件只提供 URL。

开启 `includeSubtitles`，获取 `tweetIds` 或 `startUrls` 中帖子的字幕。视频带字幕的每条帖子会增加 1 行，包含所有字幕轨道。没有视频或字幕的帖子不增加行&不收费。

```json
{ "tweetIds": ["2104593672624886205"], "includeSubtitles": true }
```

顺利完成的小型运行会跳过 `run-report` & 节省 Apify 用量。开启 `alwaysSaveRunRecords` 后，每次运行都会写入报告。

## 输出

数据行包含可用性、元数据&操作 URL。已存储的行还会加上 `storedMediaUrl` & `downloadStatus: "stored"`。**Stored Media Files** 会打开已存储的记录。

示例使用样例值。实际结果反映实时数据。照片行如下所示。

```json
{
  "type": "photo",
  "width": 1200,
  "height": 675,
  "altText": "Sample alt text",
  "sourceTarget": "OpenAI"
}
```

字幕行带有 `resultType: "subtitles"` & 位于 `tracks` 中的字幕轨道。

```json
{
  "resultType": "subtitles",
  "tweetId": "2104593672624886205",
  "tracks": [
    {
      "language": "en",
      "name": "Sample captions.srt",
      "autoGenerated": false,
      "url": "https://video.twimg.com/subtitles/sample.vtt",
      "text": "Sample caption text.",
      "cues": [{ "startMs": 0, "endMs": 3370, "text": "Sample caption text." }]
    }
  ]
}
```

X 自行转写音频时，`autoGenerated` 为 `true`。`url` 指向该轨道的 WebVTT 文件。媒体过滤条件不会去掉字幕行。开启 `downloadMedia` 时，字幕行带有 `downloadStatus: "url-only"`。

## 输出列

运行读到每行后，8 个输入会调整该行的形式。它们不运行代码&不改变价格。

| 字段                | 作用                                        |
| ------------------- | ------------------------------------------- |
| `fields`            | 只保留这些字段，顺序&拼写与你写的一致       |
| `omitFields`        | 去掉这些字段&保留其余字段                   |
| `renameFields`      | 把字段移到使用新名称的列中                  |
| `flatten`           | 把每个嵌套对象展开为顶层列                  |
| `fillMissingFields` | 某行缺少保留的字段时，填入 `null`。默认开启 |
| `joinFields`        | 把这些列表各自合并为 1 个文本值             |
| `joinSeparator`     | 合并项之间的文本。默认是逗号&空格           |
| `constantFields`    | 添加每行文本都相同的列                      |

- 用点号表示对象内的字段。大小写&下划线都没有影响。
- 每行都保留它的 `id`。
- 使用 `fields` 时，某行缺少的字段会以 `null` 输出。这样每行的列都相同。
- 字段名写错时，运行会在读取前停止&不收取任何费用。
- 如果无法检查字段名，运行会继续读取&把未见过的字段名列在最后。
- 运行会忽略为其他 Actor 编写的映射函数或 jq 过滤器。

## 限制&恢复

提取中断时，会写入免费的 `partial` 诊断。已获取的结果不受影响。重试前，先查看 `availableResults`、`failedTargets`、`retryable` & `nextAction`。Actor 成功退出只说明结果已交付，不代表提取完整。

运行状态会写明提前停止的每个原因。`stopCauses` 列出每个原因，并附上各自的 `message`、`retryable` & `nextAction`。原因包括 `target_not_found`、`target_suspended`、`target_failed`、`pagination_safety_limit`、`reply_reach` & `deadline_reached`。`target_suspended` 会写明被 X 冻结的账号。`reply_reach` 表示 X 只提供了回复串的一部分。只有在其他原因让运行停止时，缺失或被冻结的目标才会列入其中。只要任何原因可重试，整个运行就是 `retryable`。

## 常见问题

先解答常见问题，再说明在哪里获取帮助。

### 我需要 X API 密钥或登录吗？

不需要。Xquik 的 X Media Downloader 不需要 X API 密钥、登录或任何凭据。

### 下载 X 媒体合法吗？

Xquik 的 X Media Downloader 请求的是公开的 X 字段。结果可能包含个人数据。请确认用途合法&遵守适用的隐私规定。不确定时，请咨询专业律师。

### 为什么我的运行没有返回结果？

先查看运行状态。空运行的状态会提示你检查目标&过滤条件。出现需要注意的情况时，会生成免费的 `diagnostics` 输出。其中的 `stopCauses` 为每个原因给出可以照做的 `nextAction`。运行会列出它无法读取的每个输入&说明修正方法。

### 可以使用 API、定时调度&集成吗？

可以。你可以从 50 个公开任务或 Xquik REST API 中选择。[API 标签页](https://apify.com/xquik/x-media-downloader/api) 提供 Python、JavaScript & cURL 示例。Apify [定时调度](https://docs.apify.com/platform/schedules) 可以按 cron 运行 Xquik 的 X Media Downloader。Agent 使用 [Apify MCP](https://docs.apify.com/platform/integrations/mcp)。除非需要旧版构建，否则请使用 `latest`。

### 在哪里获取帮助？

在 [Issues 标签页](https://apify.com/xquik/x-media-downloader/issues) 提交 issue，并附上运行 ID。键值存储中的免费诊断信息会说明需要注意的运行。没有返回任何行的运行，会在状态中说明原因。

### 可以获得定制方案吗？

可以。在 [Issues 标签页](https://apify.com/xquik/x-media-downloader/issues) 中说明你的需求。Xquik 还提供仪表盘、REST API、MCP 服务器 & webhook。在 Xquik 的 [Apify 主页](https://apify.com/xquik) 上可以找到它的网站。
