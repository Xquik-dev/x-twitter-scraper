## How to download X media

New to Apify?
[Create a free account](https://console.apify.com/sign-up?fpr=xquik) first. The

1. Open Xquik's X Media Downloader in Apify Console.
2. Add handles to `twitterHandles` or post URLs to `startUrls`.
3. Pick `sources` & turn on `downloadMedia` to store files.
4. Set `maxItems` to cap delivered rows, then click Start.
5. Download the dataset as JSON, CSV or Excel, or use the Apify API.

`startUrls` & `profileUrls` take each URL as a plain string or as a
`{ "url": "..." }` object.

```json
{ "profileUrls": ["https://x.com/nasa", { "url": "https://x.com/OpenAI" }] }
```

`profileUrls` & `tweetIds` work as targets too.

## Input

```json
{
  "twitterHandles": ["OpenAI"],
  "sources": ["profiles"],
  "downloadMedia": true,
  "maxItems": 10000
}
```

One target is enough. Turn on `downloadMedia` to store files. Files above 80 MB
stay URL-only.

Turn on `includeSubtitles` to get the subtitles of posts in `tweetIds` or
`startUrls`. Each post whose video has captions adds 1 row with every caption
track. A post without video or captions adds no row & costs nothing.

```json
{ "tweetIds": ["2104593672624886205"], "includeSubtitles": true }
```

Small runs that go well skip `run-report` & save Apify usage. Turn on
`alwaysSaveRunRecords` to write it on every run.

## Output

Rows include availability, metadata & action URLs. Stored rows add
`storedMediaUrl` & `downloadStatus: "stored"`. **Stored Media Files** opens the
stored records.

Examples use sample values. Results reflect live data. A photo row looks like
this.

```json
{
  "type": "photo",
  "width": 1200,
  "height": 675,
  "altText": "Sample alt text",
  "sourceTarget": "OpenAI"
}
```

A subtitles row has `resultType: "subtitles"` & its caption tracks in `tracks`.

```json
{
  "resultType": "subtitles",
  "tweetId": "2104593672624886205",
  "tracks": [
    {
      "language": "en",
      "name": "Sample captions.srt",
      "autoGenerated": false,
      "url": "https://video.twimg.com/subtitles/sample.vtt",
      "text": "Sample caption text.",
      "cues": [{ "startMs": 0, "endMs": 3370, "text": "Sample caption text." }]
    }
  ]
}
```

`autoGenerated` is `true` when X transcribed the audio itself. `url` links the
track's WebVTT file. Media filters leave subtitles rows in. With `downloadMedia`
on, a subtitles row has `downloadStatus: "url-only"`.

## Output columns

8 inputs shape each row after the run reads it. They run no code & change no
price.

| Field               | What it does                                                |
| ------------------- | ----------------------------------------------------------- |
| `fields`            | Keep only these fields, in the order & spelling you write   |
| `omitFields`        | Drop these fields & keep the rest                           |
| `renameFields`      | Move a field to a column with a new name                    |
| `flatten`           | Turn each nested object into top-level columns              |
| `fillMissingFields` | Fill a kept field a row lacks with `null`. On by default    |
| `joinFields`        | Turn each of these lists into 1 text value                  |
| `joinSeparator`     | Text between joined items. The default is a comma & a space |
| `constantFields`    | Add a column with the same text on every row                |

- Use a dot for a field inside an object. Case & underscores do not matter.
- Every row keeps its `id`.
- With `fields`, a field a row lacks arrives as `null`. Every row then has the
  same columns.
- A wrong field name stops the run before it reads & charges nothing.
- If names cannot be checked, the run reads on & lists unseen names last.
- The run ignores a map function or jq filter written for another Actor.

## Limits & recovery

Interrupted extraction writes a free `partial` diagnostic. Available results
stay intact. Read `availableResults`, `failedTargets`, `retryable` &
`nextAction` before you retry. A successful Actor exit confirms delivery, not
complete extraction.

The run status names every cause of an early stop. `stopCauses` lists each cause
with its own `message`, `retryable` & `nextAction`. The causes are
`target_not_found`, `target_suspended`, `target_failed`,
`pagination_safety_limit`, `reply_reach` & `deadline_reached`.
`target_suspended` names the accounts X suspended. `reply_reach` means X served
only part of a reply thread. A missing or suspended target joins the list only
when another cause stopped the run. The run is `retryable` when any cause is.

## FAQ

Answers to common questions, then where to get help.

### Do I need an X API key or login?

No. Xquik's X Media Downloader needs no X API key, login or credentials.

### Is it legal to download X media?

Xquik's X Media Downloader requests public X fields. Results can contain
personal data. Confirm a lawful purpose & follow applicable privacy rules. Ask
qualified counsel when uncertain.

### Why did my run return no results?

Read the run status first. An empty run's status says to check your targets &
filters. The free `diagnostics` output appears when something needs attention.
Its `stopCauses` gives each cause a `nextAction` to follow. The run lists each
input it cannot read & says how to fix it.

### Can I use the API, schedules & integrations?

Yes. Choose from 50 public tasks or the Xquik REST API. The
[API tab](https://apify.com/xquik/x-media-downloader/api) has Python, JavaScript
& cURL examples. Apify [schedules](https://docs.apify.com/platform/schedules)
run Xquik's X Media Downloader on a cron. Agents use
[Apify MCP](https://docs.apify.com/platform/integrations/mcp). Use `latest`
unless you need an older build.

### Where do I get help?

Open an issue in the
[Issues tab](https://apify.com/xquik/x-media-downloader/issues) with the run ID.
Free diagnostics in the key-value store explain runs that need attention. A run
that gets no row back says why in its status.

### Can I get a custom solution?

Yes. Describe what you need in the
[Issues tab](https://apify.com/xquik/x-media-downloader/issues). Xquik also
offers a dashboard, a REST API, an MCP server & webhooks. Find Xquik's website
on its [Apify profile](https://apify.com/xquik).
