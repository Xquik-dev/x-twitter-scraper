Xquikは世界最速かつ最安値のX(Twitter)スクレイパーサービスで、最も網羅的なXデータを提供します。XquikのX Media Downloaderは、ポスト&プロフィールから写真、動画&GIFを抽出または保存します。他のApify Actorの多くは、フィルタリングや重複排除の前に課金します。Xquikが課金するのは、配信した結果のうち、重複がなくフィルター条件に合うものだけです。

ポスト&プロフィールのメディアタブから、Twitterのメディアをダウンロードしたり、直接URLを抽出したりできます。料金は**配信された行1件につき$0.00015**で、プラットフォームの利用料はApifyが別途請求します。X APIキーもログインも不要です。

> Xquikは独立したサードパーティサービスです。X Corpとは提携していません。
> 「Twitter」および「X」はX Corpの商標です。

## X Media Downloaderを使う理由

- **あらゆる取得元のメディア。** `sources` で、ポスト、プロフィールのメディアタブ、返信、引用ポスト&スレッドを選べます。
- **ファイルの保存もおまかせ。** `downloadMedia` をオンにすると、ファイルを保存し、`storedMediaUrl` のリンクを返します。
- **必要なメディアだけ。** プロフィールのメディアを、種類、日付、言語、表示回数、いいね、返信、リポストで絞り込めます。
- **すべての字幕を1行に。** `includeSubtitles` をオンにすると、動画付きポストのすべての字幕トラックを取得できます。
- **すぐに使えるエクスポート。** フィールドの選択、名前の変更、フラット化、結合をしてから、JSON、CSV、Excel、XML、RSSでエクスポートできます。

## Xのメディアをダウンロードする方法

Apifyを初めて使いますか？まず[無料アカウントを作成してください](https://console.apify.com/sign-up?fpr=xquik)。無料プランはクレジットカード不要&毎月$5分を使えます。1メディア行あたり$0.00015なので、プラットフォーム利用料を別にすると、$5で最大33,000件のメディア行をまかなえます。その後、このページに戻ってTry for freeを押してください。

1. Apify ConsoleでXquikのX Media Downloaderを開きます。
2. ユーザー名を `twitterHandles` に、またはポストのURLを `startUrls` に追加します。
3. `sources` を選び、ファイルを保存するには `downloadMedia` をオンにします。
4. `maxItems` で配信する行数の上限を決め、Startをクリックします。
5. データセットをJSON、CSV、Excelのいずれかでダウンロードするか、Apify APIを使います。

`startUrls` & `profileUrls` は、各URLを文字列のまま、または `{ "url": "..." }` オブジェクトとして受け取ります。

```json
{ "profileUrls": ["https://x.com/nasa", { "url": "https://x.com/OpenAI" }] }
```

`profileUrls` & `tweetIds` も対象として使えます。

## 入力

```json
{
  "twitterHandles": ["OpenAI"],
  "sources": ["profiles"],
  "downloadMedia": true,
  "maxItems": 10000
}
```

対象は1つで足ります。ファイルを保存するには `downloadMedia` をオンにしてください。80MBを超えるファイルはURLだけになります。

`tweetIds` や `startUrls` のポストの字幕を取得するには、`includeSubtitles` をオンにしてください。動画に字幕があるポストごとに、すべての字幕トラックを含む行が1件加わります。動画も字幕もないポストは行を追加せず、料金もかかりません。

```json
{ "tweetIds": ["2104593672624886205"], "includeSubtitles": true }
```

問題なく終わった小規模な実行は、`run-report` を省いてApifyの利用料を節約します。毎回書き込むには `alwaysSaveRunRecords` をオンにしてください。

## 出力

行には、表示可否、メタデータ&アクションのURLが入ります。保存した行には `storedMediaUrl` & `downloadStatus: "stored"` が加わります。**Stored Media Files** を開くと、保存したレコードを見られます。

例はサンプル値です。結果にはライブデータが反映されます。写真の行は次のようになります。

```json
{
  "type": "photo",
  "width": 1200,
  "height": 675,
  "altText": "Sample alt text",
  "sourceTarget": "OpenAI"
}
```

字幕の行には `resultType: "subtitles"` が入り、`tracks` にその字幕トラックが入ります。

```json
{
  "resultType": "subtitles",
  "tweetId": "2104593672624886205",
  "tracks": [
    {
      "language": "en",
      "name": "Sample captions.srt",
      "autoGenerated": false,
      "url": "https://video.twimg.com/subtitles/sample.vtt",
      "text": "Sample caption text.",
      "cues": [{ "startMs": 0, "endMs": 3370, "text": "Sample caption text." }]
    }
  ]
}
```

`autoGenerated` は、Xが音声を自動で文字起こしした場合に `true` になります。`url` はトラックのWebVTTファイルへのリンクです。メディアのフィルターは字幕の行を除外しません。`downloadMedia` がオンのとき、字幕の行は `downloadStatus: "url-only"` になります。

## 出力の列

実行が各行を読み取った後、8つの入力でその形を整えます。コードの実行&料金の変更はありません。

| フィールド | 動作 |
| --- | --- |
| `fields` | 書いたとおりの順序&表記で、指定したフィールドだけを残す |
| `omitFields` | 指定したフィールドを除き、残りを保持する |
| `renameFields` | フィールドを新しい名前の列に移す |
| `flatten` | 入れ子の各オブジェクトをトップレベルの列にする |
| `fillMissingFields` | 残すフィールドが行にない場合は `null` で埋める。デフォルトでオン |
| `joinFields` | 指定した各リストを1つのテキスト値にする |
| `joinSeparator` | 結合した項目の間に入るテキスト。デフォルトはカンマ&スペース |
| `constantFields` | すべての行に同じテキストが入る列を加える |

- オブジェクト内のフィールドは、ドットでつないで指定します。大文字小文字&アンダースコアの違いは問いません。
- どの行も `id` を残します。
- `fields` を使うと、行にないフィールドは `null` として届きます。そのため、どの行も同じ列を持ちます。
- フィールド名が間違っていると、読み取り&課金の前に実行が止まります。
- 名前を確認できない場合、実行は読み取りを続け、見当たらなかった名前を最後に挙げます。
- 他のActor向けに書いたマップ関数やjqフィルターは、実行が無視します。

## Xのメディアのダウンロードにはいくらかかりますか？

どのApifyプランでも、配信された行1件につき$0.00015です。プラットフォームの利用料は、Apifyが別途請求します。

より多くの量が必要なら、前払いの利用枠が多い[Apifyプランを選んでください](https://apify.com/pricing?fpr=xquik)。

- 課金は配信したデータ行1件につき1回です。`diagnostics` の診断情報は無料です。
- 字幕の行は、トラック数にかかわらず1行です。
- 開始、URL、ファイル、画質の料金はかかりません。
- 重複排除は課金の前に行います。

## 制限&復旧

抽出が中断されると、無料の `partial` 診断を書き込みます。取得できた結果はそのまま残ります。再試行する前に `availableResults`、`failedTargets`、`retryable` & `nextAction` を確認してください。Actorの正常終了が示すのは配信の完了です。抽出が最後まで終わったことは意味しません。

実行ステータスは、早期停止の原因をすべて示します。`stopCauses` は各原因を挙げ、それぞれに `message`、`retryable` & `nextAction` を付けます。原因は `target_not_found`、`target_suspended`、`target_failed`、`pagination_safety_limit`、`reply_reach` & `deadline_reached` です。`target_suspended` は、Xが凍結したアカウントを示します。`reply_reach` は、Xが返信スレッドの一部しか返さなかったことを示します。存在しない対象や凍結された対象が一覧に入るのは、別の原因で実行が止まった場合だけです。いずれかの原因が再試行可能なら、実行も `retryable` になります。

## よくある質問

よくある質問に答えたあと、サポートを受けられる場所を案内します。

### X APIキーやログインは必要ですか？

いいえ。XquikのX Media Downloaderは、X APIキー、ログイン、認証情報を必要としません。

### Xのメディアをダウンロードしても合法ですか？

XquikのX Media Downloaderは、Xの公開フィールドを取得します。結果には個人データが含まれることがあります。目的が合法であることを確認し、適用されるプライバシー規則に従ってください。判断に迷う場合は、資格のある弁護士に相談してください。

### 実行結果が0件だったのはなぜですか？

まず実行ステータスを確認してください。結果が空の実行では、ステータスが対象&フィルターの確認を促します。対応が必要なことがあると、無料の `diagnostics` 出力が現れます。その `stopCauses` は、原因ごとに従うべき `nextAction` を示します。実行は、読み取れない入力をすべて挙げ、直し方を示します。

### API、スケジュール&連携は使えますか？

はい。50個の公開タスクかXquik REST APIから選べます。[APIタブ](https://apify.com/xquik/x-media-downloader/api)には、Python、JavaScript & cURLの例があります。Apifyの[スケジュール](https://docs.apify.com/platform/schedules)で、XquikのX Media Downloaderをcronで実行できます。エージェントは[Apify MCP](https://docs.apify.com/platform/integrations/mcp)を使います。古いビルドが必要な場合を除き、`latest` を使ってください。

### どこでサポートを受けられますか？

実行IDを添えて、[Issuesタブ](https://apify.com/xquik/x-media-downloader/issues)でissueを開いてください。キーバリューストアにある無料の診断情報が、対応が必要な実行について説明します。行が1件も返らなかった実行は、その理由をステータスで示します。

### カスタムソリューションを依頼できますか？

はい。必要な内容を[Issuesタブ](https://apify.com/xquik/x-media-downloader/issues)に書いてください。Xquikは、ダッシュボード、REST API、MCPサーバー & Webhookも提供しています。Xquikのウェブサイトは、Xquikの[Apifyプロフィール](https://apify.com/xquik)にあります。
