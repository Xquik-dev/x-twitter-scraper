Xquik è il servizio di scraping X (Twitter) più veloce & economico al mondo, con
i dati X più completi. X Jobs Scraper di Xquik raccoglie le offerte di lavoro
pubblicate su X, con stipendi, link di candidatura & descrizioni complete. La
maggior parte degli altri Actor Apify fa pagare prima di filtrare o deduplicare.
Xquik fa pagare solo i risultati consegnati, unici e conformi ai filtri.

Cerca le offerte di lavoro di X per parola chiave, luogo, modalità di lavoro,
livello di esperienza & azienda in 1 esecuzione. Paghi **$0.00015 per riga
consegnata**, & Apify fattura a parte l'uso della piattaforma. Non ti servono
una chiave API X né il login.

> Xquik è un servizio di terze parti indipendente. Non è affiliato a X Corp.
> "Twitter" e "X" sono marchi di X Corp.

## Ricerche & dati sulle offerte di lavoro

- Molti termini di ricerca in 1 esecuzione, letti in parallelo.
- Filtri su luogo, modalità di lavoro, livello di esperienza, tipo di contratto
  & azienda.
- URL & ID delle offerte letti come annunci completi.
- Località di lavoro per nome, ciascuna con l'ID che `locationId` accetta.
- Titolo, fascia retributiva, valuta, link di candidatura, località & account
  che assume.
- Descrizioni complete in testo semplice & Markdown su ogni riga.
- Attribuzione della ricerca su ogni riga.
- Rimozione dei duplicati tra le ricerche prima della fatturazione.
- Export JSON, CSV, Excel, XML & RSS tramite i dataset di Apify.
- Le esecuzioni riprendono dallo stato salvato dopo una migrazione di Apify.

## Come estrarre le offerte di lavoro di X

Non usi ancora Apify?
[Crea prima un account gratuito](https://console.apify.com/sign-up?fpr=xquik).
Il piano gratuito non richiede carta di credito & offre $5 da spendere ogni
mese. A $0.00015 per offerta, $5 coprono fino a 33.000 offerte, senza contare
l'uso della piattaforma. Poi torna qui & premi Try for free.

1. Apri X Jobs Scraper di Xquik in Apify Console.
2. Inserisci titoli di lavoro o competenze in `searchTerms`, oppure gli URL
   delle offerte in `startUrls`.
3. Restringi la ricerca con `location`, `locationType`, `seniority` o `company`.
4. Imposta `maxItems` per limitare le righe consegnate, poi fai clic su Start.
5. Scarica il dataset in JSON, CSV o Excel, oppure usa l'API di Apify.

`startUrls` accetta ogni URL come stringa semplice o come oggetto
`{ "url": "..." }`.

```json
{
  "startUrls": [
    "https://x.com/i/jobs/1899202395210649861",
    { "url": "https://x.com/i/jobs/1899202395210649861" }
  ]
}
```

## Input

Cerca per parola chiave con i filtri.

```json
{
  "searchTerms": ["software engineer", "data scientist"],
  "location": "Berlin",
  "locationType": ["remote", "hybrid"],
  "seniority": ["senior", "lead"],
  "maxItems": 200
}
```

`locationType` accetta `onsite`, `remote` & `hybrid`. `seniority` accetta
`intern`, `entry_level`, `junior`, `mid_level`, `senior`, `lead`, `manager` &
`executive`. `employmentType` accetta `full_time`, `full_time_contract`,
`part_time` & `contract_to_hire`. Ogni filtro mantiene le offerte che
corrispondono a uno qualsiasi dei valori scelti.

Leggi offerte note tramite URL o ID.

```json
{
  "startUrls": [{ "url": "https://x.com/i/jobs/1899202395210649861" }],
  "jobIds": ["1828221151962898435"]
}
```

`location` accetta il nome di un luogo. `locationId` fissa invece 1 luogo
esatto, come New York City anziché West New York.

Trova gli ID dei luoghi per nome. Un'esecuzione con `locationSearchTerms` elenca
i luoghi invece delle offerte.

```json
{ "locationSearchTerms": ["New York"], "maxItems": 20 }
```

Le esecuzioni piccole senza problemi saltano `run-report` & risparmiano uso di
Apify. Attiva `alwaysSaveRunRecords` per scriverlo a ogni esecuzione.

## Output

Ogni offerta è 1 riga del dataset con `id`, `title`, `url`, `applyUrl`,
`location`, i campi dello stipendio & `account`. Ogni riga riporta anche
`description`, `descriptionMarkdown`, `locationType`, `employmentType`,
`seniorityLevel`, `jobFunction`, `team`, `postedAt` & `company`. Imposta
`includeDetails` su `false` per un'esecuzione più veloce con i soli campi
dell'elenco. Le righe ottenute dagli URL delle offerte riportano sempre
l'annuncio completo. I campi di origine mancanti restano assenti. X Jobs Scraper
di Xquik non inventa valori.

Gli esempi usano valori fittizi. I risultati contengono dati live. Una riga di
offerta ha questo aspetto.

```json
{
  "id": "1899202395210649861",
  "title": "Engineer",
  "url": "https://x.com/i/jobs/1899202395210649861",
  "applyUrl": "https://example.com/careers/engineer",
  "location": "United States",
  "locationType": "remote",
  "employmentType": "full_time",
  "seniorityLevel": "lead",
  "formattedSalary": "Starting at $225K",
  "salaryMin": 225000,
  "salaryCurrencyCode": "USD",
  "salaryInterval": "annually",
  "account": { "username": "example", "verified": true },
  "sourceTarget": "software engineer",
  "resultType": "job"
}
```

Ogni località di lavoro è 1 riga con l'`id` che `locationId` accetta.

```json
{
  "id": "1720462281920696805",
  "name": "New York City, NY",
  "sourceTarget": "New York",
  "resultType": "jobLocation"
}
```

## Colonne di output

8 input danno forma a ogni riga dopo che l'esecuzione la legge. Non eseguono
codice & non cambiano il prezzo.

| Campo               | Cosa fa                                                                        |
| ------------------- | ------------------------------------------------------------------------------ |
| `fields`            | Tiene solo questi campi, nell'ordine & con la grafia che scrivi                |
| `omitFields`        | Scarta questi campi & tiene il resto                                           |
| `renameFields`      | Sposta un campo in una colonna con un nuovo nome                               |
| `flatten`           | Trasforma ogni oggetto annidato in colonne di primo livello                    |
| `fillMissingFields` | Riempie con `null` un campo tenuto che manca in una riga. Attivo di default    |
| `joinFields`        | Trasforma ognuno di questi elenchi in 1 valore di testo                        |
| `joinSeparator`     | Testo tra gli elementi uniti. Il valore predefinito è una virgola & uno spazio |
| `constantFields`    | Aggiunge una colonna con lo stesso testo su ogni riga                          |

- Usa un punto per un campo dentro un oggetto. Maiuscole & trattini bassi non
  contano.
- Ogni riga conserva il suo `id`.
- Con `fields`, un campo che manca in una riga arriva come `null`. Così ogni
  riga ha le stesse colonne.
- Un nome di campo sbagliato ferma l'esecuzione prima di leggere & non addebita
  nulla.
- Se i nomi non si possono controllare, l'esecuzione continua a leggere & elenca
  per ultimi i nomi che non ha visto.
- L'esecuzione ignora una funzione map o un filtro jq scritti per un altro
  Actor.

## Limiti & recupero

X Jobs Scraper di Xquik legge molte ricerche & URL di offerte in 1 esecuzione.
Le righe consegnate & i progressi restano dopo un riavvio di Apify. L'Actor non
aggiunge un limite di tempo proprio. Rispetta qualsiasi timeout di Apify che
imposti.

Un'estrazione interrotta scrive una diagnostica `partial` gratuita. I risultati
disponibili restano intatti. Leggi `availableResults`, `failedTargets`,
`retryable` & `nextAction` prima di riprovare. Un'uscita riuscita dell'Actor
conferma la consegna, non l'estrazione completa.

Lo stato dell'esecuzione nomina ogni causa di un arresto anticipato.
`stopCauses` elenca ogni causa con i propri `message`, `retryable` &
`nextAction`. Le cause sono `target_not_found`, `target_failed`,
`pagination_safety_limit` & `deadline_reached`. Un target mancante entra
nell'elenco solo se un'altra causa ha fermato l'esecuzione. L'esecuzione è
`retryable` quando lo è almeno una causa.

## FAQ

Le risposte alle domande più comuni, poi dove trovare assistenza.

### Serve una chiave API X o il login?

No. X Jobs Scraper di Xquik non richiede chiave API X, login o credenziali.

### È legale estrarre le offerte di lavoro di X?

X Jobs Scraper di Xquik raccoglie campi pubblici di X. I risultati possono
contenere dati personali. Verifica di avere uno scopo lecito & rispetta le norme
sulla privacy applicabili. Nel dubbio, chiedi a un legale qualificato.

### Perché la mia esecuzione non ha restituito risultati?

Leggi prima lo stato dell'esecuzione. Lo stato di un'esecuzione vuota ti dice di
controllare termini di ricerca & filtri. L'output gratuito `diagnostics` compare
quando qualcosa richiede attenzione. Il suo `stopCauses` assegna a ogni causa un
`nextAction` da seguire. Un valore di filtro che l'Actor non conosce ferma
l'esecuzione prima di qualsiasi addebito & indica i valori da usare.

### Posso usare l'API, le pianificazioni & le integrazioni?

Sì. Usa l'API di Apify o l'API REST di Xquik. La
[scheda API](https://apify.com/xquik/x-job-scraper/api) ha esempi in Python,
JavaScript & cURL. Le
[pianificazioni](https://docs.apify.com/platform/schedules) di Apify avviano X
Jobs Scraper di Xquik con un cron. Gli agenti usano
[Apify MCP](https://docs.apify.com/platform/integrations/mcp). Usa `latest`, a
meno che non ti serva una build precedente.

### Dove trovo assistenza?

Apri una issue nella
[scheda Issues](https://apify.com/xquik/x-job-scraper/issues) con l'ID
dell'esecuzione. La diagnostica gratuita nel key-value store spiega le
esecuzioni che richiedono attenzione. Un'esecuzione che non riceve nessuna riga
ne spiega il motivo nel suo stato.

### Posso avere una soluzione personalizzata?

Sì. Descrivi ciò che ti serve nella
[scheda Issues](https://apify.com/xquik/x-job-scraper/issues). Xquik offre anche
una dashboard, un'API REST, un server MCP & webhook. Trovi il sito web di Xquik
sul suo [profilo Apify](https://apify.com/xquik).
